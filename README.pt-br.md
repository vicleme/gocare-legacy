# GoCare

*[Read this in English](README.md)*

Plataforma web de transporte especializado e acessível para pessoas com deficiência e outros grupos com necessidades específicas de mobilidade. Trabalho de Conclusão de Curso (TCC) — Análise e Desenvolvimento de Sistemas, Fatec Praia Grande, 2021.

---

## Sobre o projeto

O GoCare foi construído a partir de uma pesquisa com mais de 180 respostas sobre os desafios enfrentados por pessoas com deficiência ao usar aplicativos de transporte por aplicativo — recusas de motoristas, falta de veículos adaptados e discriminação. A proposta é uma plataforma que conecta motoristas capacitados a passageiros com necessidades específicas, incluindo cadastro, agendamento de corridas e avaliação mútua.

**Principais achados da pesquisa:**
- 73,2% dos respondentes são ou conhecem pessoalmente uma pessoa com deficiência
- 69,4% já vivenciaram ou conheciam alguém que vivenciou problemas relacionados a transporte
- 131 sugestões foram coletadas para orientar o desenvolvimento do produto

## Identidade visual

- **Nome:** GoCare — "Go" + "Care", com "Car" embutido dentro de "Care"
- **Slogan:** *TakeCare. WeCare. GoCare.*
- **Símbolo:** um volante de direção fundido ao Símbolo Internacional de Acessibilidade (ONU, 2015)
- **Paleta de cores:** testada para contraste em casos de baixa visão e diferentes tipos de daltonismo

## Stack tecnológica

- **Front-end:** HTML5, CSS3, JavaScript, Bootstrap
- **Back-end:** PHP 7 (mysqli)
- **Banco de dados:** MySQL
- **Hospedagem original:** 000webhost (não está mais no ar; hospedagens gratuitas desse tipo não têm manutenção de longo prazo)

## Escopo implementado

Cadastro e autenticação de motoristas e passageiros, agendamento/cancelamento/avaliação de corridas, edição de perfil e desativação/exclusão de conta. A **página de Notificações foi projetada mas não implementada** — ficou definida como funcionalidade futura para alertar os usuários sobre mudanças nas corridas.

## Status

Este repositório preserva o projeto como foi entregue como TCC em 2021 — não está em desenvolvimento ativo. Uma versão de portfólio navegável, sem dependência de back-end/banco de dados, está sendo construída separadamente.
